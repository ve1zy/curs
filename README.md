# КР: Рекомендация режимов работы ректификационной колонны К-2 (ЭЛОУ-АВТ)

Рекомендательная система на основе машинного обучения: по текущему технологическому
профилю (сырьё, сезон, цели) ранжирует исторические режимы работы колонны К-2 и
выдаёт топ-K режимов, наиболее вероятно обеспечивающих нужное качество фракций и
выход целевых продуктов.

**Тема:** «Рекомендация режимов работы ректификационной колонны атмосферно-вакуумной перегонки нефти»
**Направление НИР ОНПЗ:** MES
**Защита:** до 21.12.2026

## Суть задачи

- «Пользователь» в рек. системе = **технологический профиль** (тип нефти, расход,
  сезон, целевой продукт, ограничения по качеству), ~20 штук;
- «Айтем» = **исторический режим работы колонны К-2** (температуры, давление,
  орошения, пар), ~5000–6000 штук;
- «Рейтинг» = **пригодность режима под профиль** (−1…+1), считается ретроспективно
  по близости результата к целям (регламент):
  - +1.0 — результат в регламенте, +0.5 — допустимо но не оптимально,
  - 0 — не применялся, −1.0 — выход за регламент;
- система **не считает режим с нуля** — она ранжирует зафиксированные в истории
  комбинации параметров по релевантности текущей ситуации.

**Критерий релевантности:** выход целевых фракций ±5 % от целевого И налегание
5–95 ≤ 10 °C.

## Модели

1. **CF kNN** (baseline) — косинусная близость векторов параметров режимов;
   вариант на «входных» параметрах (сырьё, расход, сезон).
2. **ALS** — матричное разложение «профиль × режим», скрытые факторы, работа с
   пропусками.
3. **Гибрид** — `score = α·als + β·content − γ·constraint_penalty − δ·energy_penalty`,
   веса подбираются grid search'ом.

## Метрики

`Precision@5`, `NDCG@5`, `MAP@5` + доменные: `tech_corridor_rate` (доля режимов без
нарушения регламента), `avg_overlap` (налегание фракций), `energy_ratio`
(энергоэффективность).
