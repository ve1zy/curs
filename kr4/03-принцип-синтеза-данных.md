# Принцип синтеза исходных данных

## 1. Общая идея

Реальные журналы АСУТП установки ЭЛОУ-АВТ в учебном проекте недоступны. Поэтому
используется синтетический датасет. Его цель — не воспроизвести промышленный
процесс с инженерной точностью, а создать данные с понятными зависимостями, на
которых можно корректно сравнить алгоритмы рекомендаций.

Данные строятся по причинной схеме:

```text
тип сырья + сезон + производственная цель
                    │
                    ▼
          технологический профиль
                    │
                    ▼
      параметры режима работы колонны
                    │
                    ▼
  выходы фракций + налегание + сера + энергия
                    │
                    ▼
             оценка пригодности
```

Таким образом, значения не генерируются полностью независимо. Сначала задаются
условия процесса, затем параметры режима, затем результат работы колонны. Это
создаёт зависимость «режим → результат», необходимую для машинного обучения.

## 2. Уровни данных

### 2.1. Свойства сырья

Для каждого типа нефти задаются условные характеристики:

- плотность, кг/м³;
- содержание серы, %;
- доля лёгких фракций, %.

Плотность влияет на требуемые температуры и выход тяжёлых фракций. Доля лёгких
фракций влияет на потенциальный выход бензина и дизельной фракции. Содержание серы
используется при проверке ограничения качества.

### 2.2. Технологический профиль

Профиль формируется комбинацией:

```text
тип сырья × сезон × целевой продукт
```

Профиль содержит:

- тип нефти;
- сезон;
- целевой продукт: бензин или дизель;
- плановый расход сырья;
- целевой выход продукта;
- максимальное содержание серы;
- максимально допустимое налегание фракций.

В текущем ноутбуке используется 8 типов сырья, 2 сезона и 2 цели, то есть
`8 × 2 × 2 = 32` профиля. Это соответствует формулировке «около 20 профилей»;
при необходимости объём можно уменьшить выбором части комбинаций.

### 2.3. Режим работы

Для каждого режима генерируются параметры колонны. Часть параметров является
условиями процесса, часть — управляющими воздействиями.

| Группа | Признаки |
|---|---|
| Условия | тип сырья, сезон, расход сырья |
| Температурные | температура питания, верха, низа, боковых выводов |
| Гидродинамические | давление, острое орошение, ПЦО-1, ПЦО-2 |
| Энергетические | расход водяного пара |
| Исторические | дата, смена |

Сначала параметры выбираются из реалистичных диапазонов. Затем между связанными
параметрами задаются зависимости. Например:

```text
температура низа = температура питания + 12 °C + шум
температура питания = базовая температура − поправка на плотность + шум
```

Это лучше, чем независимая генерация, потому что в реальном технологическом
процессе параметры колонны связаны между собой.

## 3. Упрощённая модель результата

Результаты рассчитываются по регрессионным зависимостям с физическим смыслом.
Полный материальный и тепловой баланс колонны в рамках работы не строится.

Перед расчётом параметры нормируются:

```text
reflux_norm = (reflux − 35) / 80
steam_norm  = (steam_pct − 1.2) / 2.3
feed_norm   = (feed_temp − 300) / 60
```

Пример зависимости выхода бензина:

```text
gasoline_yield =
    16
    + 0.42 · light_fraction
    + 4 · reflux_norm
    + 2 · feed_norm
    − 3 · density_norm
    + noise
```

Интерпретация:

- больше лёгких фракций в сырье повышает выход бензина;
- увеличение орошения влияет на разделение и выход лёгких продуктов;
- температура питания влияет на распределение фракций;
- тяжёлая нефть снижает потенциальный выход бензина.

Выход дизельной фракции рассчитывается через долю лёгких фракций, расход пара,
орошение и температуру питания. Оставшаяся часть материального баланса относится
к мазуту:

```text
residue_yield = 100 − gasoline − kerosene − diesel − heavy_fraction
```

## 4. Модель качества и энергозатрат

Налегание фракций должно уменьшаться при более эффективном разделении. Поэтому
используется зависимость:

```text
overlap =
    19
    − 7 · reflux_norm
    − 4 · steam_norm
    + 5 · density_norm
    + noise
```

Расход энергии увеличивается с расходом сырья, пара и орошения:

```text
energy =
    0.75
    + 0.004 · feed_rate
    + 0.18 · steam_pct
    + 0.002 · reflux
    + noise
```

Содержание серы определяется исходным типом нефти и немного уменьшается при
увеличении расхода пара. Полученные значения ограничиваются снизу и сверху, чтобы
не появлялись физически бессмысленные результаты.

## 5. Шум и неудачные режимы

В каждую модель добавляется случайный шум. Например:

```python
rng.normal(0, 1.2, N_MODES)
```

Шум нужен по трём причинам:

1. реальные измерения содержат погрешности;
2. одинаковые параметры не должны всегда давать абсолютно одинаковый результат;
3. модели должны сравниваться на неоднозначных данных, а не на идеально
   разделимых примерах.

Часть режимов становится неудачной из-за сочетания тяжёлого сырья, большого
налегания, недостаточного орошения или превышения ограничения по сере.

## 6. Расчёт рейтинга

Для каждого профиля проверяется каждый исторический режим. Режим считается
релевантным, если:

```text
|фактический выход целевой фракции − целевой выход| ≤ 5 %
и налегание ≤ 10 °C
и содержание серы ≤ установленного ограничения
```

Затем учитывается соответствие типа сырья и сезона:

| Условие | Рейтинг |
|---|---:|
| Сопоставимые сырьё/сезон и результат соответствует качеству | `+1.0` |
| Результат соответствует качеству, но сырьё/сезон отличаются | `+0.5` |
| Сопоставимые сырьё/сезон, но результат неудовлетворительный | `−1.0` |
| Нет сопоставимого применения и результат неудовлетворительный | `0.0` |

Дополнительно сохраняется бинарный признак `relevant`:

```text
relevant = 1, если режим удовлетворяет критериям
relevant = 0, иначе
```

Он используется для расчёта `Precision@5`, `MAP@5` и `NDCG@5`.

## 7. Почему такой принцип подходит для работы

Синтетический набор обладает нужными свойствами:

- известны причины формирования каждого результата;
- соблюдаются заданные диапазоны технологических параметров;
- между признаками есть корреляции;
- присутствует шум и неудачные режимы;
- существует зависимость между профилем, режимом и результатом;
- можно воспроизводимо получить одинаковый CSV благодаря `SEED = 42`;
- можно отдельно оценить качество рекомендаций и соблюдение технологических
  ограничений.

Ограничение метода: коэффициенты модели являются учебными приближениями, а не
данными промышленной идентификации. Поэтому полученные рекомендации демонстрируют
методику построения прототипа и не предназначены для непосредственного управления
реальной колонной К-2.
