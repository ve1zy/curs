# Постановка задачи

## 1. Предметная область: установка ЭЛОУ-АВТ и колонна К-2

Установка ЭЛОУ-АВТ (электрообессоливание и атмосферно-вакуумная перегонка) —
головная технологическая установка Омского НПЗ, на которой сырая нефть доводится
до товарного качества и разделяется на фракции. Атмосферная часть установки
предназначена для выделения лёгких и средних фракций из отбензиненной нефти.

Ректификационная колонна **К-2** — основной аппарат атмосферной перегонки. В её
низ подаётся отбензиненная нефть, нагретая в печи до температуры питания; в колонне
происходит разделение на следующие фракции:

| Продукт | Место вывода |
|---------|--------------|
| Тяжёлый бензин | верх колонны |
| Керосиновая фракция (180–220 °C) | боковой погон 1 |
| Лёгкая дизельная фракция (220–280 °C) | боковой погон 2 |
| Тяжёлая дизельная фракция (280–350 °C) | боковой погон 3 |
| Мазут | низ колонны |

Качество разделения определяется чёткостью работы колонны: чем меньше взаимное
«налегание» температурных пределов соседних фракций, тем лучше разделение и тем
выше выход целевых продуктов.

## 2. Технологический режим колонны

Режим работы колонны задаётся набором технологических параметров:

| Группа | Параметры |
|--------|-----------|
| Условия (неуправляемые входы) | тип (состав) сырья, расход сырья, сезон |
| Управляющие параметры | температура питания, температуры верха/низа, температуры вывода боковых фракций, давление вверху |
| Расходные параметры | расход острого орошения, расходы ПЦО-1/ПЦО-2 (промежуточные циркуляционные орошения), расход водяного пара в низ и стриппинг-секции |
| Паспортные / исторические | дата, смена |

Типовые диапазоны значений (из открытых источников):

- температуры питания/фракций: 140–355 °C;
- давление вверху колонны: 0,15–0,5 МПа;
- расход водяного пара: 1,2–3,5 % масс. на сырьё.

Результат работы режима — выход фракций (% масс.), чёткость разделения (налегание
5–95), содержание серы, энергозатраты.

## 3. Формальная постановка как задачи рекомендаций

Задача формулируется в терминах рекомендательных систем:

| Сущность | Роль в рек. системе | Состав |
|----------|---------------------|--------|
| Технологический профиль `p` | «Пользователь» | тип нефти, расход сырья (т/ч), сезон, целевой продукт (максимизация бензина/дизеля), ограничения по сере, желаемая чёткость разделения |
| Режим работы `m` | «Айтем» | температуры (питание, верх, низ, боковые выводы), давление, расходы орошений и пара, дата, смена |
| Исход режима `o(m)` | Атрибут айтема | выход фракций (% масс.), налегание 5–95, содержание серы, энергозатраты |

**Взаимодействие** — матрица «технологический профиль × режим», где значение —
оценка пригодности режима под данный профиль, вычисленная ретроспективно:

| Оценка | Смысл |
|--------|-------|
| +1.0 | режим применялся при аналогичных условиях, результат попал в регламент |
| +0.5 | режим применялся, результат допустимый, но не оптимальный |
| 0 | режим не применялся при таких условиях |
| −1.0 | режим применялся, результат вышел за регламент |

**Задача.** Для текущего профиля `p` построить ранжированный список исторических
режимов `M_p = top-K`, максимизирующий долю режимов, обеспечивающих требуемое
качество фракций и выход целевых продуктов, при минимальных нарушениях
технологических ограничений.

**Отличие от расчётного моделирования.** Система не рассчитывает режим «с нуля» —
она ранжирует зафиксированные в истории комбинации параметров по релевантности
текущей ситуации.

## 4. Критерий релевантности (формализован заранее)

Режим `m` релевантен профилю `p`, если одновременно:

1. выход целевых фракций в коридоре ±5 % от целевого значения профиля;
2. чёткость разделения: налегание 5–95 ≤ 10 °C.

Критерий даёт двоичную метку релевантности, используемую во всех метриках качества.

## 5. Данные

Реальные исторические логи АСУТП недоступны для учебной работы, поэтому данные
симулируются:

- справочник типов сырья (западно-сибирская лёгкая, тяжёлая смесь и др., ~8 типов)
  с характеристиками: плотность, содержание серы, фракционный состав;
- справочник технологических профилей: тип нефти × сезон × целевой ассортимент ×
  ограничения по качеству (~20 профилей);
- генерация ~6000 режимов: случайные значения параметров в реалистичных диапазонах
  с учётом технологических связей (температура питания коррелирует с температурой
  низа; расход орошения влияет на температуру верха);
- упрощённая модель «режим → результат»: выход фракций как функция от температуры
  питания, расхода орошения и расхода пара; чёткость разделения как функция от
  флегмового числа и L/V-соотношения;
- вариации по типам сырья и сезонам (летний/зимний ассортимент).

Для различимости моделей в данные намеренно вносится шум, включаются «плохие»
режимы с нарушениями регламента, а часть режимов делается применимой только для
определённых типов сырья.

## 6. Модели

1. **Коллаборативная фильтрация (item-based kNN)** — baseline. Косинусная близость
   между векторами параметров режимов; для текущего профиля — k ближайших режимов в
   пространстве параметров, ранжирование по исторической оценке пригодности.
   Дополнительный вариант: схожесть только по «входным» параметрам (температура
   питания, расход сырья, тип нефти), чтобы отделить условия от управляющих
   воздействий.
2. **Матричное разложение (ALS)** — скрытые факторы профилей и режимов на матрице
   оценок от −1 до +1; прогноз — скалярное произведение факторных векторов.
   Преимущества: работа с пропусками, выявление скрытых паттернов (например,
   сцепление «летние профили с лёгкой нефтью» и «режимы с повышенным ПЦО» в один
   фактор).
3. **Гибридная модель** — взвешенная комбинация:

   ```
   score = α · als_score + β · content_score − γ · constraint_penalty − δ · energy_penalty
   ```

   где `content_score` — косинусная близость условий текущего профиля с условиями,
   при которых режим исторически показал хороший результат; `constraint_penalty` —
   штраф за выход параметров режима за регламентные пределы для данного сырья;
   `energy_penalty` — штраф за энергозатраты. Веса подбираются на валидационной
   выборке grid search'ом по сетке 0.1 (при нехватке времени — фиксированные
   0.5/0.5).

## 7. Метрики качества

| Метрика | Что измеряет |
|---------|--------------|
| NDCG@5 | качество ранжирования топ-5 с учётом позиции релевантных режимов |
| MAP@5 | средняя precision по топ-5 |
| Precision@5 | доля релевантных режимов в топ-5 |
| tech_corridor_rate (доменная) | доля рекомендованных режимов без нарушения технологических ограничений для текущего сырья |
| avg_overlap (доменная) | среднее налегание фракций (°C) в рекомендациях — чем ниже, тем лучше чёткость |
| energy_ratio (доменная) | среднее отношение энергозатрат рекомендованного режима к минимально возможным при сопоставимом качестве |

Разбиение данных: 80/20 по парам «профиль–режим».

## 8. Схема системы (общая структура дальнейшей работы)

```
   сырьё, сезон, цели          история режимов + исходы
        │                              │
        ▼                              ▼
 ┌──────────────┐   матрица    ┌──────────────┐
 │  профиль p   │─────────────▶│  режимы M    │
 └──────────────┘ оценок при-  └──────────────┘
                   годности        │
                                   ▼
                    ┌──────────────────────────┐
                    │  Рекомендатор (CF kNN /  │
                    │  ALS / гибрид)           │
                    └──────────────────────────┘
                                   │
                                   ▼
                    top-K режимов + пояснения (метрики, штрафы)
```
